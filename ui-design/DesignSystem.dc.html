IITM Beacon — Design System

Built on the OGE Exchange Student Guide system (see its own design-system canvas) for spacing, radius, and flat no-shadow surfaces — but the brand red, near-black text, and typeface below are verified directly against the live ge.iitm.ac.in stylesheet, not just the reference's logo-derived guess: its `--red` is `#AE152D` and its body font is Roboto, not the maroon `#781F19` / Public Sans the reference had assumed. The pieces marked "originated" have no precedent in the reference and were designed to extend the same vocabulary: the 0–10 score gradient, OTP code input, and the custom checkbox/select/toggle controls it never needed.

Layout — corrected against the live site

Border radius scale — only these 5 values, anywhere

The reference's cards sat at a tight 6px. ge.iitm.ac.in's own compiled CSS rounds its cards to 12px instead — noticeably softer — so cards (and card-like blocks: side-cards, group-blocks, table containers) moved there; small controls moved from 4px to 6px to keep the scale's proportions.

2px — decorative only
6px — buttons, inputs, small badges
8px — search boxes, empty states
12px — cards
999px — chips, pills, toggles

Elevation — corrected against the live site

Border + soft shadow

The reference's "no shadows, ever" rule doesn't hold on the live site — ge.iitm.ac.in's own compiled CSS has real box-shadow values. Every card keeps its 1px line border for a crisp edge, plus this soft, cool-toned lift lifted directly from that stylesheet: 0 8px 24px rgba(148, 156, 168, 0.2).

Border only — old rule
Border + shadow — current
